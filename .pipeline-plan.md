# Pipeline Refactor Plan

- `Renderer` owns Vulkan runtime only: device, queues, swapchain, render pass, command pools, and submission.
- `ChunkBindings` owns the shared descriptor set layout used by both compute and graphics pipelines.
- `ChunkToTexPipeline` owns compute pipeline creation and dispatch helpers.
- `RaytracerPipeline` owns graphics pipeline creation, camera push constants, binding, and fullscreen draw.
- `ChunkResources` owns GPU chunk memory and descriptor sets allocated from `ChunkBindings`.
- `Game` owns the pipeline handles and chunk resources, and records per-frame work through those handles.
